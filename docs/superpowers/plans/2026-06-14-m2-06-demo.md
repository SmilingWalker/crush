## Design seam corrections (vs master task doc `03-m2-delegate-runner.md:579-634`)

The master task doc is the approved design intent. The following are **verified implementation deviations**, each backed by cited evidence from the M2 codebase at agent-team tip `2678d0bd`. They reshape M2-06 from a naive "launch crush and paste a prompt" script into an honest hybrid demo.

### Seam 1: The production `AgentFactory` does not exist — the real LLM demo cannot run yet

The master doc's `demo-m2-task.md` (line 596) says "启动 crush" and the acceptance (line 633) says "脚本可手动执行，3 delegate 并行可见." That flow assumes a real delegate launches a real LLM-backed session agent. **It cannot today.** Evidence:

- `internal/team/delegate_runner.go:24-27` (M2-01 comment): *"M1-04 shipped the AgentFactory/TurnRunner interfaces but no production implementation. ... the real factory (backed by sessionAgent) is a follow-up task. Until then the runner is exercised by mock-factory tests."*
- `internal/agent/team_call.go:108-113` (M1-04): `AgentFactory` is an interface with one method `BuildRunner(ctx, spec) (TurnRunner, error)`. There is **no** production type in `internal/agent` or `internal/team` that implements it against the real `sessionAgent`; only the test mock in `internal/team/delegate_runner_test.go`.
- `internal/agent/team_call.go:54-55` (M2-03 comment): *"生产 AgentFactory（尚未落地）负责把该 ToolPolicyProfile 映射到构建 runner 的 config"* — confirms the policy-to-config wiring also awaits the production factory.

**Decision — hybrid demo:** `demo-m2.sh` exposes two modes:

1. **`./scripts/demo-m2.sh --smoke`** (runs TODAY): builds crush, then runs `go test ./internal/team/ -run '^TestDelegateDemoSmoke$' -v` — a new **test-only** function (added in this task, in the existing `internal/team/delegate_runner_test.go` test file, gated so it never runs in the normal suite via `testing.Short()` skip — see Task 2). It wires the existing mock factory, drives a 3-delegate group through `running → done` and a cancel path, and prints the `DelegateGroupRenderContext.RenderTool` compact+expanded output and the `AggregateResults` markdown to stdout. This proves the script plumbing works and shows the operator exactly what the transcript will look like. No real LLM, no network.
2. **`./scripts/demo-m2.sh` (default / `--live`)** (gated on prerequisites): prints the prompt to paste and a banner that says "PREREQUISITES NOT MET — see scripts/demo-m2-prerequisites.md. Run --smoke for the runnable preview." If a future build ever wires a config/env gate (Seam 2), the script's only change is swapping the banner for an actual `crush` invocation; the prompt and task doc are already correct.

**Why not "just label it deferred" (no runnable artifact):** M2-06 is the milestone close-out; shipping zero executable evidence would leave the operator with nothing to verify and would mean the master doc's "脚本可手动执行" acceptance is unmet. The `--smoke` mode satisfies it honestly within the real constraint. **Why not fake a live run:** pretending to call `crush` and sleep would be dishonest and would break if the prerequisites land mid-milestone. The hybrid is the honest path.

### Seam 2: `Experimental.AgentTeamPreview` does not exist; the UI gate is a package-level `atomic.Bool`

The master doc's `demo-m2-task.md` step 1 (line 595) says "启动 crush（确保 AgentTeamPreview=true）." **There is no such flag.** Evidence:

- `internal/ui/chat/delegate.go:18-26` (M2-04): the gate is `var delegateUIEnabled atomic.Bool` — a package-level switch, inert by default. Its doc comment explicitly says: *"Until the Experimental.AgentTeamPreview config flag lands (open architecture issue #8) ... the gate is a package-level switch so the renderer is inert by default."*
- The renderer reads `delegateUIEnabled.Load()` at three points — `delegate.go:285` (`Render`), `:296` (`RawRender`), `:311` (`RenderTool`) — and returns `""` whenever the flag is off. So even if Seam 1's factory existed, the operator would see **no** delegate UI.
- There is **no** config struct field, env var, or CLI flag that flips `delegateUIEnabled`. Only `setDelegateUIEnabledForTest` (unexported, `delegate.go:31`) sets it, and only tests call it.

**Decision:** `demo-m2-prerequisites.md` documents this as blocker #2 and gives the exact one-line change the M2-04 comment itself prescribes (`delegate.go:23-25`): *"When the flag ships, swap the single `delegateUIEnabled.Load()` read in `RenderTool` for `cfg.Experimental.AgentTeamPreview` (a one-line change; the rest of the renderer is flag-agnostic)."* The `--smoke` mode is unaffected: the smoke **test** calls `setDelegateUIEnabledForTest(true)` (same as the existing M2-04 renderer tests) so its printed output reflects the enabled renderer, independent of any config plumbing.

### Seam 3: `demo-m2-task.md` content — faithful to master doc, with prerequisite callouts

The master doc (lines 588-629) gives the full scenario, T1–T4 expected behaviors, and verification checklist. **Adopted verbatim** with two honest additions:

No behavioral spec from the master doc is dropped or weakened.

### Seam 4: Scope — `scripts/` + one test-only function; no production code

- **Files created:** `scripts/demo-m2.sh`, `scripts/demo-m2-task.md`, `scripts/demo-m2-prerequisites.md`.

// TestDelegateDemoSmoke is the runnable M2-06 demo preview. It is gated by
// testing.Short() so the normal `go test ./...` suite skips it; the demo
// launcher opts in via a non-short `go test -run TestDelegateDemoSmoke -v`.
//
// It wires the mock factory, launches a 3-delegate read-only group, cancels it
// mid-flight, and prints the live compact-line skeleton plus the final
// AggregateResults markdown. No real LLM, no network — it shows exactly the
// wiring the live demo will exercise once the two prerequisites (production
// AgentFactory + Experimental.AgentTeamPreview flag; see
// scripts/demo-m2-prerequisites.md) land. The printed compact line is a
// faithful skeleton derived from real group state, NOT a chat.RenderTool call
// (that would import-cycle team→chat).
func TestDelegateDemoSmoke(t *testing.T) {
	if testing.Short() {
		t.Skip("demo smoke; run via scripts/demo-m2.sh --smoke")
	}
	// One delegate completes fast (50ms); two are long (2s) so the cancel
	// below catches them mid-flight — mirroring the live demo's T3/T4. The
	// mock factory selects behavior by spec.AgentType, and M2-01 derives
	// spec.AgentType from DelegateTask.AgentID (delegate_types.go:19-21), so
	// the fast task carries AgentID "fast".
	factory := &mockAgentFactory{
		defaultDelay:  2 * time.Second,
		defaultResult: completedResult(),
		overrides: map[string]mockBehavior{
			"fast": {delay: 50 * time.Millisecond, result: completedResult()},
		},
	}
	runner := NewDelegateRunner(factory)

	tasks := []DelegateTask{
		{ID: "1", Prompt: "find all SQL migrations and their schemas", AgentID: "fast"},
		{ID: "2", Prompt: "find all HTTP API route definitions", AgentID: "explore"},
		{ID: "3", Prompt: "find all Go interface definitions", AgentID: "explore"},
	}
	group := runner.RunGroup(context.Background(), tasks)
	require.NotNil(t, group)

	// Let the fast delegate finish, then snapshot live state — the skeleton
	// of the compact UI line ("Delegates N running / M done"). Use the
	// exported RunningCount/DoneCount helpers (delegate_types.go:70,83) so
	// the demo's accounting matches the production read path exactly.
	time.Sleep(100 * time.Millisecond)
	fmt.Printf("\n[M2 DEMO SMOKE] compact line skeleton: Delegates %d running / %d done\n",
		group.RunningCount(), group.DoneCount())

	// Cancel the in-flight group — exercises M2-02's CancelGroup path the
	// live demo's T4 (Esc → cancel prompt) reaches.
	require.NoError(t, runner.CancelGroup(group.ID))
	group.Wait()

	// Print the real AggregateResults markdown (M2-05) — the exact summary
	// the parent agent tool returns to the model.
	fmt.Println("[M2 DEMO SMOKE] AggregateResults markdown:")
	fmt.Println(AggregateResults(group))
}
```

#!/usr/bin/env bash
# M2 delegate-runner end-to-end demo launcher.
#
# Two modes:
#   ./scripts/demo-m2.sh --smoke   Run TODAY: mock-backed smoke preview
#                                 (builds crush, runs TestDelegateDemoSmoke,
#                                 prints render skeleton + AggregateResults).
#   ./scripts/demo-m2.sh           Live demo path. Needs two prerequisites
#   ./scripts/demo-m2.sh --live    (see scripts/demo-m2-prerequisites.md);
#                                 until they land it prints the prompt to
#                                 paste + a prerequisite banner.
#
# No bashisms beyond what git-bash on win32 supports (set -euo pipefail,
# forward slashes, /dev/null). Portable.

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
REPO_ROOT="$(cd "$SCRIPT_DIR/.." && pwd)"
MODE="${1:---live}"

print_prompt() {
    cat <<'PROMPT'
Demo prompt (paste into crush once prerequisites are met):

    Search the entire codebase for:
    a) All SQL migration files and their schemas
    b) All HTTP API route definitions
    c) All Go interface definitions
    Use 3 delegates in parallel.

See scripts/demo-m2-task.md for the T1-T4 expected behaviors and the
verification checklist.
PROMPT
}

case "$MODE" in
    --smoke)
        echo "[M2 DEMO] building crush (go build ./cmd/crush)..."
        (cd "$REPO_ROOT" && go build ./cmd/crush)
        echo "[M2 DEMO] running mock-backed smoke preview..."
        (cd "$REPO_ROOT" && go test ./internal/team/ -run '^TestDelegateDemoSmoke$' -v)
        echo "[M2 DEMO] smoke done. For the live demo, see scripts/demo-m2-prerequisites.md."
        ;;
    --live|"")
        echo "[M2 DEMO] LIVE DEMO — PREREQUISITES NOT MET."
        echo "[M2 DEMO] Two blockers must clear first (see scripts/demo-m2-prerequisites.md):"
        echo "[M2 DEMO]   1. Production AgentFactory (internal/agent/team_call.go:108)"
        echo "[M2 DEMO]   2. Experimental.AgentTeamPreview config flag (internal/ui/chat/delegate.go:26)"
        echo "[M2 DEMO] Run './scripts/demo-m2.sh --smoke' for the runnable preview today."
        echo
        print_prompt
        ;;
    *)
        echo "usage: $0 [--smoke|--live]" >&2
        exit 2
        ;;
esac
```
