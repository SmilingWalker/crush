# M4-13 E2E Test Plan

> Status: in-progress | File: `internal/team/e2e_test.go` (NEW)

## Goal

M4 E2E: 6 end-to-end scenarios exercising the full M4 stack (Service + TeamRunner + MemberRunner + Scheduler + Mailbox + Shutdown + Recovery) over in-memory SQLite.

## Architecture

All tests use:
- `newE2EFixture(t)` -- creates an in-memory SQLite with all migrations, builds a Service with all 10 stores + feature gate enabled, returns `(Service, *sql.DB, *db.Queries)`.
- Mock `TurnRunner` implementations from `member_runner_test.go` (`recordingTurnRunner`, `blockingTurnRunner`).
- `stubAgentFactory` from `member_runner_test.go`.

### Critical: newServiceFixture Signature Fix

The existing `newServiceFixture` in `service_test.go` is missing `NewDependencyStore(q)` and therefore has a compile error. Our `newE2EFixture` includes ALL required parameters:

```go
func newE2EFixture(t *testing.T) (Service, *sql.DB) {
    sqlDB, q := newStoreFixture(t)
    svc := NewService(
        sqlDB,
        NewTeamStore(q), NewMemberStore(q), NewTaskStore(q),
        NewRunStore(q), NewEventStore(q), NewAuditStore(q),
        NewMailboxStore(q), NewSessionLinkStore(q), NewDependencyStore(q),
        WithEnabledGate(func() bool { return true }),
    )
    return svc, sqlDB
}
```

## 6 E2E Scenarios

### 1. SpawnMember E2E (`TestE2E_SpawnMember`)
- CreateTeam → SpawnMember via TeamRunner → verify member registered and idle
- Wake the member → verify Run completes → verify member returns to idle
- Verifies: TeamRunner.SpawnMember, MemberRunner.Start, MemberRunner.loop, MemberRunner.handleWake, Service.StartRun, Service.FinishRun

### 2. Message E2E (`TestE2E_MessageFlow`)
- CreateTeam → SpawnMember("leader") + SpawnMember("worker")
- leader sends direct message to worker via Service.SendMessage
- Verify: message stored, receipt created, worker can read unread messages
- leader sends broadcast → verify both members get receipts
- Verifies: Service.SendMessage (direct + broadcast), MailboxStore, recipient resolution

### 3. Task Report E2E (`TestE2E_TaskReport`)
- CreateTeam → SpawnMember("worker")
- CreateTask via Service → worker claims task via ClaimNextTask (Scheduler)
- Worker reports task complete via team_report_status tool (simulating model response)
- Verify: task status transitions queued→assigned→completed, member status idle
- Verifies: Service.CreateTask, Scheduler.ClaimNextTask, Service.UpdateTask, NewTeamReportStatusTool

### 4. Cancel Turn E2E (`TestE2E_CancelTurn`)
- CreateTeam → SpawnMember with blocked `blockingTurnRunner`
- Wake the member → member gets stuck in running state
- TeamRunner.CancelMemberTurn → verify cancel sequence completes
- Verify member ends in stopped state, run marked canceled
- Verifies: TeamRunner.CancelMemberTurn, MemberRunner.Shutdown(StopCancel), Service.MarkRunTerminal

### 5. Shutdown Team E2E (`TestE2E_ShutdownTeam`)
- CreateTeam → SpawnMember("m1") + SpawnMember("m2")
- TeamRunner.StopTeam(StopCancel) → both members stopped
- Verify all members terminal (stopped/failed)
- Verify events recorded
- Verifies: TeamRunner.StopTeam, MemberRunner.Shutdown, Service.PublishMemberEvent

### 6. Recovery E2E (`TestE2E_StaleRecovery`)
- CreateTeam → SpawnMember → StartRun
- Wait for heartbeat to be "stale" (cutoff test: FindStaleRuns with future cutoff)
- Scheduler.RecoverStaleRuns → mark run interrupted
- Scheduler.StartupRecovery → restore member to idle
- Verify: run status interrupted, member idle, recovery report populated
- Verifies: Service.FindStaleRuns, Scheduler.RecoverStaleRuns, Scheduler.StartupRecovery, MarkRunTerminal
