## Design Seams Resolved

1. **M4-03 acceptance #4 (deferred)**: Active member with no active run restored to idle. M4-08 implements via `StartupRecovery` — scans members listed in recovery report, checks if their current_run_id is now interrupted, transitions them back to idle.

2. **InterruptedReason**: New enum type in `recovery.go`. Three values: `crashed` (member crashed), `heartbeat_lost` (heartbeat stopped), `leader_shutdown` (leader-initiated). Stored as string in team_runs.error field (already exists, free-form). Also surfaced in StaleRunInfo.

3. **usage_status semantics**: Defined in `scheduler.go` as consts: `UsageStatusFinal` ("final") — run completed/failed normally; `UsageStatusPartial` ("partial") — run interrupted mid-turn, partial cost data exists; `UsageStatusUnknown` ("unknown") — run interrupted before any cost recorded. M4-08 sets `partial` for heartbeat-lost interruptions, `unknown` for runs that were `queued` (never started). M4-12 Cost Accounting consumes these.

4. **Widen MarkRunTerminal guard (Seam 10)**: M4-03 hardcodes `expected_status='running'` in the store layer. Runs found by `FindStaleRuns` with status `queued` or `waiting_permission` silently fail to match. M4-08 passes the actual expected status through, so stale runs in any active status can be transitioned to `interrupted`.

## Task 1: Expand Recovery Types (recovery.go)

Add `InterruptedReason` enum and expand `StaleRunInfo` with reason + usage_status fields.

```go
// InterruptedReason classifies why a run was interrupted.
type InterruptedReason string

const (
    InterruptedCrashed         InterruptedReason = "crashed"
    InterruptedHeartbeatLost   InterruptedReason = "heartbeat_lost"
    InterruptedLeaderShutdown  InterruptedReason = "leader_shutdown"
)

// UsageStatus categorizes the cost-data completeness of a terminal run.
const (
    UsageStatusFinal   = "final"
    UsageStatusPartial = "partial"
    UsageStatusUnknown = "unknown"
)

// StaleRunInfo gains InterruptedReason and UsageStatus (M4-03 had RunID/TeamID/MemberID/Status/LastHeartbeat).

    MemberID          string            `json:"member_id"`

    LastHeartbeat     time.Time         `json:"last_heartbeat"`
    InterruptedReason InterruptedReason `json:"interrupted_reason"`

```

```go
func (s *sqlcRunStore) MarkRunTerminal(ctx context.Context, tx *sql.Tx, teamID, runID string, status RunStatus, expectedStatus RunStatus, runErr string, usageStatus string, at time.Time) error {
    qtx := s.q.WithTx(tx)
    return qtx.MarkRunTerminal(ctx, db.MarkRunTerminalParams{
        Status:      string(status),
        FinishedAt:  sql.NullInt64{Int64: at.UnixMilli(), Valid: true},
        Error:       sql.NullString{String: runErr, Valid: runErr != ""},
        UsageStatus: sql.NullString{String: usageStatus, Valid: usageStatus != ""},
        ID:          runID, TeamID: teamID,
        Status_2: string(expectedStatus),
    })
}
```

## Task 4: StartupRecovery (scheduler.go)

New method `StartupRecovery` that:
1. Calls `RecoverStaleRuns` to mark stale runs as interrupted
2. For each member whose run was interrupted, restores member state to `idle`
3. Returns a combined `StartupRecoveryReport`

```go
type StartupRecoveryReport struct {
    RunsRecovered    int `json:"runs_recovered"`
    MembersRestored  int `json:"members_restored"`
}

func (s *Scheduler) StartupRecovery(ctx context.Context) (*StartupRecoveryReport, error) {
    report, err := s.RecoverStaleRuns(ctx)
    if err != nil {
        return nil, err
    }
    
    // Collect member IDs from recovered runs
    memberIDs := map[string]struct{}{}
    for _, info := range report.Details {
        memberIDs[info.MemberID] = struct{}{}
    }
    
    // Restore each member to idle
    restored := 0
    for memberID := range memberIDs {
        if err := s.svc.UpdateMemberState(ctx, UpdateMemberStateRequest{
            ID:     memberID,
            Status: MemberIdle,
        }); err != nil {
            // Non-fatal: log and continue
            continue
        }
        restored++
    }
    
    return &StartupRecoveryReport{
        RunsRecovered:   report.InterruptedCount,
        MembersRestored: restored,
    }, nil
}
```
