## Architecture

### 6 Design Seams

1. **Pure rendering, not standalone panel** — TeamCompactItem/ExpandedTeamView are rendering components (not tea.Model). Produce styled strings.

2. **TeamStatusProvider interface** — narrow single-method interface matching `TeamRunner.Status()`. Renderer holds optional provider.

3. **24-line truncation** — ExpandedTeamView counts lines: header+summary (~6 lines) + members (max 18). Scroll offset for pagination, j/k navigate.

4. **StatusIcon shared** — Extract panel.go's local `statusIcon` to exported `StatusIcon()` in compact.go. panel.go 1-line edit.

5. **No proto types** — TeamRunner.Status() returns domain types directly. compact.go imports `internal/team`.

6. **Scrolling in expanded view** — j/k navigate, scrollOffset tracks position, footer adjusts for hidden counts.
