# M4.5b Message Wake & Session Gap Fixes — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix 3 gaps in the leader→member message pipeline: (1) no wake after SendMessage, (2) member has no session ID, (3) leader tool can't access TeamRunner.

**Architecture:** Add `WakeMember` to TeamRunner interface so leader tools can wake recipients. Add `createSession` func field to MemberRunner so it auto-creates a session on first wake if none exists. Wire session creator through TeamRunner → MemberRunner.

**Tech Stack:** Go, team.Service, team.TeamRunner, session.Service (from internal/session)

// if the member is not found in the registry.

- [ ] **Step 2: Implement WakeMember on teamRunner**

After the `Status` method implementation (around line 249), add:

```go
func (t *teamRunner) WakeMember(ctx context.Context, teamID, memberID string, source WakeSource) error {
	t.mu.RLock()
	mr, ok := t.members[memberID]
	t.mu.RUnlock()
	if !ok {
		return fmt.Errorf("member %s not found in team %s", memberID, teamID)
	}
	mr.Wake(source)
	return nil
}
```
