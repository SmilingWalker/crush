# M5.1: Team Member Tool Loop & Session Fix

> 状态：spec | 里程碑：M5.1 | 日期：2026-06-17
> 依赖：M5 (PermissionBridge, TeamBar, Session Switching)

## 问题根因

Member 工具调用后 turn 直接终结，无法完成 multi-step agent 会话。三个串联根因：

1. **ActorContext 未注入 context** — `TurnRunnerAdapter.Run()` 丢弃 `TeamAgentCall.Actor`，导致 `actor.FromContext(ctx)` 永远返回空。PermissionBridge 无法识别 team session，绕过 bridge 直接走 `permissionService.Request()` → block 在 channel 上等 UI 回复。

2. **Session 未持久化** — `handleWake` 通过 `createSession` 创建 session 存入内存 `m.sessionID`，但从未写回 `team_members` 表或 `team_session_links` 表。重启后 session 丢失。

3. **StopTurn 杀 loop** — `NewPermissionDeniedResponse()` 设置 `StopTurn = true`。fantasy 库的 `processStepStream` 检查 `hasStopTurn(toolResults)` → `shouldContinue = false` → agent loop 直接 break。Member 一轮就停。

## 修复方案

### Fix 1: ActorContext 注入 (done — commit `4802d154`)

`turn_runner_adapter.go:32`:
```go
ctx = call.Actor.WithContext(ctx)
```

### Fix 2: Session 持久化 (done — commit `e40443b7`)

- Service 接口新增 `LinkSessionToMember(ctx, teamID, memberID, sessionID) error`
- `handleWake` 创建 session 后调用 `LinkSessionToMember` 写入 `team_session_links` 表

### Fix 3: StopTurn 去除

`internal/agent/tools/tools.go` — `NewPermissionDeniedResponse()`:
```go
// Before:
func NewPermissionDeniedResponse() fantasy.ToolResponse {
    resp := fantasy.NewTextErrorResponse("User denied permission")
    resp.StopTurn = true
    return resp
}

// After:
func NewPermissionDeniedResponse() fantasy.ToolResponse {
    return fantasy.NewTextErrorResponse("User denied permission")
    // StopTurn removed. Model can see denial and try alternatives.
    // Repeated identical tool calls caught by fantasy's hasRepeatedToolCalls detector.
}
```

影响面分析：
- **Team member 无 SkipRequests**: auto-deny → 软拒绝 → 模型继续
- **Leader TUI 用户点拒绝**: 软拒绝 → 模型看拒绝信息 → 换方案。重复调同个工具 ≥3 次时 `hasRepeatedToolCalls` 自动停。
- **Hook halt**: `hookedTool.Run()` 的 `resp.StopTurn = result.Halt` 不动，hook halt 仍可终止 turn。

### Fix 4: Member 表 session_id 回写

新增 `UpdateMemberSession` 方法到 MemberStore：
```sql
UPDATE team_members SET session_id = ? WHERE id = ? AND team_id = ?
```

`handleWake` 创建 session 后调用 `svc.UpdateMemberSession(ctx, m.TeamID, m.ID, sid)`。

### Fix 5: PermissionBridge 不变

ActorContext 注入后，`PermissionBridge.Request()` 的 team session 路径已生效：
- `SkipRequests() == true` → auto-allow
- `SkipRequests() == false` → auto-deny（结合 Fix 3 不再设 StopTurn）

无需额外改动。
