# M5.2: Permission System UI Bridge

> 状态：spec | 里程碑：M5.2 | 日期：2026-06-17
> 依赖：M5.1 (ActorContext injection, StopTurn removal, tool building fixes)

## 目标

让 team member 的工具权限请求能够弹窗到 TUI，用户可 Allow/Deny。同时修复 leader 权限弹窗不出现的预存 bug。

## 架构

```
ActiveSessionTracker (新增)
  ↓ 提供当前活跃 session ID
PermissionBridge (改造)
  ├─ Leader 路径 (无 ActorContext) → inner.Request → TUI 弹窗
  ├─ Member 活跃路径 (用户在看这个 member) → publish + block + ResolveRequest
  └─ Member 非活跃路径 (用户在其他 session) → auto-deny (soft, 无 StopTurn)
TUI Dialog (已有，修事件路由)
  ← pubsub.Event[PermissionRequest] → openPermissionsDialog
  → 用户 Allow/Deny → PermissionBridge.ResolveRequest(reqID)
```

### Request() 改造
```go
func (b *PermissionBridge) Request(ctx, opts) (bool, error) {
    ac, hasTeam := actor.FromContext(ctx)
    if !hasTeam || ac.TeamID == "" || ac.MemberID == "" {
        // 非 team session → leader 正常流程
        return b.inner.Request(ctx, opts)
    }

    // Team session → 检查活跃 session
    activeSID := b.tracker.Get()
    if activeSID != "" && activeSID == opts.SessionID {
        // 用户正在看这个 member → 弹窗
        return b.requestWithUI(ctx, opts, ac)
    }

    // 用户在其他 session → auto-deny
    return false, nil
}
```

### requestWithUI — publish + block + resolve
```go
func (b *PermissionBridge) requestWithUI(ctx, opts, ac) (bool, error) {
    reqID := opts.ToolCallID
    ch := make(chan bool, 1)

    b.pendingMu.Lock()
    b.pendingRequests[reqID] = ch
    b.pendingMu.Unlock()

    b.queue.Enqueue(reqID, DefaultPermTimeout)

    // Publish to inner → TUI 弹窗
    b.inner.Publish(pubsub.CreatedEvent, permission.PermissionRequest{
        ID: reqID, ToolCallID: reqID, ToolName: opts.ToolName,
        SessionID: opts.SessionID, Action: opts.Action, Path: opts.Path,
    })

    select {
    case <-ctx.Done():
        b.queue.Dequeue(reqID)
        return false, ctx.Err()
    case allowed := <-ch:
        b.queue.Dequeue(reqID)
        return allowed, nil
    }
}
```

注意：**不重新实现 `permissionService.Request()` 的完整逻辑**。只用 `pendingRequests` channel + `ResolveRequest`（已有）+ `inner.Publish`（已有）。`requestMu` 串行化、`autoApproveSession` 等逻辑保留在 `inner.Request()` 里，不在 bridge 重复。
