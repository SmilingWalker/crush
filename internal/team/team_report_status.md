Update your own task status. Use this to report progress: move a task to in_progress when you start working on it, to blocked when you hit an obstacle, or to completed/failed when finished. You can only update tasks that are assigned to you or unassigned tasks you are claiming. The update is applied via CAS (compare-and-swap) — if someone else modified the task concurrently, the tool retries once; if it still fails, you should transition to blocked.
